📋 GitHub Setup — Step by Step (Roman Urdu)
Step 1 — Personal Access Token banayein: GitHub.com kholen → apni profile picture par click karein → Settings → niche scroll karke Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic).
Step 2 — Scopes select karein: Token ko koi bhi naam dein (jaise "MT Files App"). Expiration set karein. "repo" checkbox ko tick karein (ye poora access dega — files upload, repo create, sab kuch). "public_repo" bhi kaafi hai agar sirf public repos chahiye. Neeche Generate token dabayein.
Step 3 — Token copy karein: Token ek hi baar dikhta hai. ghp_... wali string copy karein aur yahan upar paste kar dein. Isay kisi ke saath share na karein.
Step 4 — Repo banayein: Upar "Create Repo on GitHub" button dabayein. App khud aapki repo bana dega (public). Ya manual: GitHub par New repository → name dein → Public select karein → Create repository.
Step 5 — Connect karein: Username, repo ka naam aur token daal kar Save / Connect dabayein. Ab My Files tab par jayein aur file upload karein — file seedha aapki GitHub repo mein chali jayegi.
⚠️ Important: GitHub API par browser se direct request karne ke liye token Authorization: Bearer header mein bhejna hota hai. GitHub isay CORS ke saath allow karta hai, lekin agar aapko network error aaye to apne browser ke extensions (adblocker) band karke try karein.
